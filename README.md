# 🎧 MP3 Downloader Bot

Telegram-бот: отправляешь ссылку на трек или видео — получаешь готовый **MP3** с обложкой и тегами, а по кнопке — текст песни с Genius.

## Возможности

- **YouTube / YouTube Music / SoundCloud** — напрямую, **Spotify** — по метаданным трека
- **Поиск по названию** — напиши «исполнитель — название», бот покажет список с YouTube и SoundCloud
- **⚡ Мгновенный кэш** — однажды скачанный трек больше не качается: бот отдаёт его по `file_id` за долю секунды
- **❤️ Избранное** — кнопка 🤍 под каждым треком, список `/favorites`
- **🕘 История** — последние скачанные треки, `/history`
- **🔥 Чарт недели** — самые популярные треки бота, `/top`
- **🎲 Случайный трек** из коллекции бота, `/random`
- **👤 Профиль** — сколько скачал, место в рейтинге, любимый исполнитель и уровень (🌱 → 👑), `/me`
- **💬 Inline-режим** — `@имя_бота название` в любом чате, и трек из кэша отправляется прямо туда
- **📝 Тексты песен с Genius** — кнопка под треком или `/lyrics исполнитель — название` (зеркала dumb / intellectual, запасной источник LRCLIB)
- Прогресс-бар скачивания `▰▰▰▰▱▱▱▱▱▱ 40%`, очередь загрузок и защита от спама (один трек на пользователя одновременно)
- Выбор качества 128 / 192 / 320 kbps и автоматическое понижение для длинных треков (лимит Telegram 50 МБ)
- Админ-панель: `/stats` (активные за сутки, новые, кэш), `/ban`, `/unban`, `/broadcast` — текстом или ответом на любое сообщение (фото, видео, аудио)

> 💬 Чтобы работал inline-режим, включи его в [@BotFather](https://t.me/BotFather): `/setinline` → выбери бота → задай подсказку, например «название трека…».

## 🔓 Обход блокировки YouTube на хостингах

YouTube часто блокирует запросы с IP датацентров («Sign in to confirm you're not a bot»). Бот обходит это сразу несколькими способами:

1. **Ротация клиентов** — YouTube пробуется с разными player_client (android, tv, ios, web_safari, web_embedded, mweb): у них разные требования к токенам, какой-нибудь обычно проходит.
2. **Cookies** — переменная `YT_COOKIES` с содержимым `cookies.txt` (бот сам чинит формат, если вставлено с телефона).
3. **Spotify fallback** — трек сначала ищется в SoundCloud, потом на YouTube.

Дополнительно можно задать переменную `PROXY_URL` (например `socks5://user:pass@host:port`) — тогда все запросы yt-dlp пойдут через прокси.

## Переменные окружения

| Переменная | Обязательно | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | токен от [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | — | ID админов через запятую (узнать: [@userinfobot](https://t.me/userinfobot)) |
| `DB_PATH` | — | путь к SQLite (по умолчанию `data/bot.db`) |
| `PORT` | — | порт health-check сервера (Render выставляет сам) |
| `PROXY_URL` | — | прокси для yt-dlp, если YouTube жёстко блокирует регион датацентра |
| `GENIUS_TOKEN` | — | Client Access Token с [genius.com/api-clients](https://genius.com/api-clients) — необязательно: без него тексты идут через зеркала |
| `GENIUS_MIRRORS` | — | свои зеркала Genius через запятую (по умолчанию уже прописаны рабочие) |
| `GENIUS_PROXY` | — | прокси для genius.com (по умолчанию берётся `PROXY_URL`) |
| `DOWNLOAD_SLOTS` | — | сколько треков качать одновременно (по умолчанию 3) |
| `YT_COOKIES` | — | содержимое `cookies.txt` с youtube.com (без него YouTube на Render не качается) |

## Локальный запуск

```bash
pip install -r requirements.txt        # нужен ещё ffmpeg: apt install ffmpeg / brew install ffmpeg
BOT_TOKEN=123:ABC ADMIN_IDS=123456789 python bot.py
```

## Деплой на Render

1. На [render.com](https://render.com) → **New → Web Service** → подключи этот репозиторий.
   - **Runtime:** Docker (Render сам найдёт `Dockerfile`; можно использовать и `render.yaml` — Blueprint).
   - **Health Check Path:** `/`
   - **Instance type:** Free.
2. В **Environment** добавь переменные:
   - `BOT_TOKEN` — токен бота
   - `ADMIN_IDS` — твой Telegram ID
3. Deploy. В логах появится `Бот запущен` — пиши боту `/start` 🚀

### ⚠️ Важно про бесплатный тариф Render

Бесплатный Web Service засыпает через ~15 минут без входящих запросов, и бот перестаёт отвечать. Решение — внешний пинг:

1. Возьми URL сервиса `https://tg-mp3-bot-xxxx.onrender.com`.
2. Заведи бесплатный монитор в [UptimeRobot](https://uptimerobot.com) с интервалом 5 минут на этот URL.
3. Теперь бот будет работать круглосуточно.

### Ограничения

- Telegram Bot API принимает файлы до **50 МБ** — для очень длинных видео бот вернёт ошибку.
- Spotify не отдаёт сами файлы, поэтому трек ищется по названию (качество как правило 320 kbps с YouTube).
- Ссылки на плейлисты: скачивается первый трек.
- На бесплатном Render база в `/tmp` очищается при перезапуске — кэш, избранное и история сбрасываются. Для постоянного хранения подключи Persistent Disk и укажи `DB_PATH` на него.

## Структура

```
bot.py         — логика бота (aiogram 3): меню, поиск, кэш, избранное, чарт, inline, тексты, админка
lyrics.py      — тексты песен: Genius + запасной LRCLIB
downloader.py  — yt-dlp + FFmpeg: поиск, ротация клиентов YouTube, конвертация в MP3
database.py    — SQLite: пользователи, кэш треков, избранное, история, статистика
Dockerfile     — образ с FFmpeg для Render
render.yaml    — blueprint для деплоя
```
